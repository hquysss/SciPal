## Review Focus
- Code có tab và dòng trống, CRLF (giáo án dán từ Word): số dòng hiện ra phải đúng → Task 1 test `keeps blank lines and CRLF`.
- Chuỗi chứa `#` hoặc `//` (`print("#1")`): không tô thành chú thích → Task 1 test `comment marker inside string`.
- Chương trình Python có `input()` nhiều hơn số giá trị cho sẵn: báo lỗi rõ thay vì treo → Task 2 test `input exhausted`.
- HTML có thuộc tính trải nhiều dòng hoặc `>` trong chuỗi thuộc tính: dòng của thẻ mở là dòng chứa `<` → Task 3 test `multiline attributes`.
- Bộ chọn CSS không hợp lệ (`p:::x`): tô sáng bỏ qua, trang vẫn hiện → Task 8 test `invalid selector`.

### Task 1 (Codex): bộ tô màu cú pháp `highlight.ts`

**Files:**
- Create: `frontend/components/code/highlight.ts`
- Test: `frontend/components/code/highlight.test.ts`

**Interfaces:**
- Produces:
  ```ts
  export type CodeLang = 'python' | 'cpp' | 'javascript' | 'html' | 'css';
  export type TokenKind = 'keyword' | 'function' | 'string' | 'number' | 'comment' | 'operator' | 'text';
  export interface Token { kind: TokenKind; text: string }
  export function highlight(code: string, lang: CodeLang): Token[][]; // một mảng token cho mỗi dòng
  ```
  HTML: tên thẻ → `function`, tên thuộc tính → `keyword`, giá trị → `string`. CSS: bộ chọn → `function`, thuộc tính → `keyword`, giá trị số có đơn vị → `number`.

- [ ] **Step 1: Viết test** — `round-trips every line` (với mỗi ngôn ngữ, `tokens.map(t => t.text).join('')` từng dòng bằng dòng gốc; số dòng bằng `code.split(/\r?\n/).length`); `keeps blank lines and CRLF`; `python keywords` (`for i in range(n - 1):` → `for`,`in` là `keyword`, `range` là `function`, `1` là `number`); `cpp` (`for (int j = 0; j < n; j++)` → `int` là `keyword`); `comment marker inside string` (`print("#1")  # chú thích` → `"#1"` là `string`, phần sau `#` thứ hai là `comment`); `html` (`<a href="x.html">` → `a` là `function`, `href` là `keyword`, `"x.html"` là `string`); `css` (`h1 { color: red; margin: 8px }` → `h1` `function`, `color` `keyword`, `8px` `number`).
- [ ] **Step 2:** `pnpm --filter @scipal/web test -- components/code/highlight` → FAIL.
- [ ] **Step 3:** Hiện thực bằng regex theo từng dòng; chú thích nhiều dòng (`/* */`, `<!-- -->`, `"""`) được mang trạng thái sang dòng sau.
- [ ] **Step 4:** Chạy lại → PASS; `pnpm --filter @scipal/web typecheck` đạt.
- [ ] **Step 5:** Commit `feat(code): syntax highlighter for the shared code panel`.

### Task 2 (Codex): ghi các bước chạy Python `code_trace.py`

**Files:**
- Create: `code_trace.py` (gốc repo, chỉ stdlib)

**Interfaces:**
- Produces: `trace(code: str, inputs: list[str]) -> dict` trả đúng dạng dữ liệu kind `code-trace` của spec Tin 10: `{ code, input, steps: [{ line, frames: [{ name, vars: { tên: { repr, items? } } }], out?, error? }], truncated? }`. Khung đầu tên `'<module>'`. Giới hạn: 500 bước, 5 giây, `items` ≤ 30 phần tử (cắt thêm phần tử `'…'`).
- CLI: `python code_trace.py file.py [--input a --input b]` in JSON ra stdout.

- [ ] **Step 1: Viết tự kiểm trong `if __name__ == '__main__' and sys.argv[1:] == ['--selftest']`** với assert: gán `s = 0; s = s + 5` → bước cuối có `s.repr == '5'`; `for` 3 vòng → dòng thân xuất hiện 3 lần; hàm `def f(a): b = a * 2; return b` gọi `f(3)` → có bước với `frames[-1].name == 'f'` và `b.repr == '6'`; biến cục bộ cùng tên biến toàn cục giữ hai giá trị khác nhau ở hai khung; `x = input('n? ')` với `inputs=['7']` → `out` chứa `n? 7`; `print(1/0)` → bước cuối có `error == 'ZeroDivisionError: division by zero'` và `line` là dòng đó; `while True: pass` → `len(steps) == 500` và `truncated is True`; `input exhausted`: hai `input()` với một giá trị → bước cuối có `error` bắt đầu bằng `EOFError`; list `[1,2]` có `items == ['1','2']`, str `'ab'` có `items == ["'a'","'b'"]`.
- [ ] **Step 2:** `python code_trace.py --selftest` → lỗi (chưa có `trace`).
- [ ] **Step 3:** Hiện thực: chạy trong tiến trình con (`multiprocessing` hoặc `subprocess` gọi lại chính file) để cắt 5 giây; `sys.settrace` chỉ ghi sự kiện `line` có `co_filename == '<lesson>'`; `builtins.input` và `sys.stdout` thay bằng bản ghi; bỏ biến tên `__*`, hàm, mô đun, lớp.
- [ ] **Step 4:** `python code_trace.py --selftest` in `ok`.
- [ ] **Step 5:** Commit `feat(content): record Python steps for code-trace blocks`.
